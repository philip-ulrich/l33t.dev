# l33t.dev

Static landing page for Phil's creator and streaming home base.

## Update Links

Edit `socialLinks` in `app.js` to update Twitch or YouTube URLs. Edit `streamSchedule` in `app.js` to change the Tuesday/Friday 7 PM Eastern schedule.

## Local Preview

Open `index.html` in a browser, or serve the folder with any static server.

## Files

- `index.html` - page structure and metadata
- `styles.css` - responsive landing page styles
- `app.js` - config-driven social links
- `assets/l33t-systems-console.png` - generated hero visual
